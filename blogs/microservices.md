# Microservices

## What is Microservices?

Microservices is a software architecture style that structures an application as a collection of small services, which can be developed, deployed, and scaled independently.

## Why Microservices?

- Scalability
- Agility
- Resilience
- Security
- Maintainability
- Portability
- Testability
- Reusability
